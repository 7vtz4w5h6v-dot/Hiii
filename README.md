# My Energy Day – GitHub Pages PWA

## Dateien hochladen

Alle Dateien aus diesem Ordner müssen direkt im Hauptverzeichnis des GitHub-Repositories liegen:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

## GitHub Pages aktivieren

1. Repository auf GitHub öffnen.
2. **Settings → Pages** auswählen.
3. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
4. Branch **main** und Ordner **/(root)** auswählen.
5. **Save** anklicken.
6. Einige Minuten warten und anschließend die angezeigte GitHub-Pages-Adresse öffnen.

## Auf dem iPhone installieren

1. Die GitHub-Pages-Adresse in Safari öffnen.
2. Auf **Teilen** tippen.
3. **Zum Home-Bildschirm** auswählen.

Die App speichert ihre Daten lokal im Browser des jeweiligen Geräts. Vor einem Wechsel des Geräts oder dem Löschen von Safari-Daten sollte in der App ein Backup exportiert werden.
